# B&B Fiori e Limoni

Bed and breakfast in una casa campidanese di fine Ottocento a Quartucciu, Cagliari. Due camere con bagno privato, cortile giardino, colazione inclusa. A 10 minuti dalla spiaggia del Poetto e dal centro di Cagliari.

**Sito:** https://bbfiorielimoni.it/  
**Indirizzo:** Via Quartu 79, Quartucciu  
**Telefono:** +39 349 847 4587  

## Struttura

Sito statico di una sola pagina, senza dipendenze né passaggi di build.

- `404.html`: pagina di errore per gli indirizzi inesistenti
- `index.html`: la pagina del sito
- `privacy.html`: informativa privacy
- `fonts/`: font ospitati in locale
- `images/`: immagini

## Modificare il sito

Apri `index.html` nel browser per vedere il risultato in locale.
Le modifiche vanno sul branch `main` tramite pull request.
